# Cuenta de cobro – formulario para celular

Página sencilla para anotar los viajes de cada corte y sacar la cuenta de cobro en PDF
con el formato de Transavinco.

- Todo está en `index.html`. Los datos se guardan solo en el celular (navegador).
- Los precios, los datos del transportador y los días de corte se cambian desde **Ajustes** dentro de la página.
- La cédula y el teléfono no están en el código: se escriben una vez en **Ajustes** en el celular.
